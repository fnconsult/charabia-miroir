# charabia-miroir

Miroir de ressources linguistiques ouvertes utilisées par [Charabia](https://charabia.fun).
On ne télécharge ici que si la source d'origine ne répond pas. Chaque fichier est copié tel
quel, sans aucune modification, et Charabia vérifie son empreinte sha256 avant de s'en servir.
